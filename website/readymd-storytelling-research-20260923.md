- [한컴 제품 설명](https://www.hancom.com/store/item/8321): 사용할 사람, 설치 환경, 전달 방식, 설치 대수를 가까이 묶는다. ReadyMD도 구매 조건이 확정되면 같은 위치에서 명확하게 답하도록 설계한다.
- [Office 소개](https://www.microsoft.com/ko-kr/microsoft-365/get-started-with-office-2024): 문서 작성·일정 관리 등 하는 일을 먼저 제시하고 제품 구성과 플랜으로 이어진다. ReadyMD도 결과 형식보다 읽기·자료 재사용을 앞에 둔다.
- [Office 비교와 FAQ](https://www.microsoft.com/ko-kr/microsoft-365/office-2024): 일회성 구매와 구독, 설치·호환·인터넷 필요 여부 등 선택에 영향을 주는 조건을 구분한다. 이는 네이버 상세페이지를 확인한 증거를 대신하지 않으며 별도의 보완 자료다.

## 6. 적용할 원칙과 피할 방식

| 관찰에서 얻은 원칙 | ReadyMD에 적용할 결정 |
| --- | --- |
| 대상이 자기 상황을 알아볼 수 있어야 다음을 읽는다 | 자료를 모으고 읽고 다시 쓰는 사람의 장면을 앞에 둔다 |
| 눈으로 확인할 결과가 있어야 기능 설명이 쉬워진다 | 같은 PDF의 읽기 전후·본문과 이미지 관계를 반복해 보여준다 |
| 사용 순서가 스토리의 뼈대가 될 수 있다 | PDF 선택 → 변환 → 결과 확인 → 읽기/활용의 하루를 따라간다 |
| 기술은 사용자가 얻는 변화와 붙어 있을 때 이해된다 | EPUB·Markdown·OCR을 각각 필요한 장면에서 한 번씩 풀이한다 |
| 행동 직전에는 사용 조건과 불안을 해결한다 | 지원 환경·외부 AI 사용 조건·한계·이용 정책을 간결하게 안내한다 |

이번 표본으로 전환율이나 인과관계를 알 수는 없다. “이 구성 덕분에 잘 팔렸다”는 결론은 내리지 않는다. 특히 기존 브랜드 인지도, 가격, 광고, 리뷰, 판매자 차이가 섞여 있다.

타이머·한정 수량·과장된 손해 강조·근거 없는 수치·가짜 후기·AI로 만든 제품 실행 화면은 채택하지 않는다. 그림자·hover·장식 외곽선 금지 등 기존 사용자 시각 규칙도 유지한다.

2. 와디즈 이미지 중심 사례의 전체 서사는 별도 시각 검수가 필요하다. 현재 확인하지 못한 이미지 내용을 추정해 표에 채우지 않았다.
3. 대상 고객 인터뷰와 ReadyMD 실출력 비교로 계획의 표현을 검증한다. 경쟁 페이지의 방식은 기획 가설의 근거이며 우리 고객에게도 통한다는 증거는 아니다.
