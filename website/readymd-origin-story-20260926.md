# ReadyMD 제작 이야기와 개인 서재

## 사용자에게서 받은 제작 배경

2026-09-26 사용자가 제공한 이야기다. 연구에 앞서 PDF를 인식시키는 데 시간과 토큰을 써버리는 문제를 겪었고, AI가 잘 읽을 수 있는 자료를 먼저 만드는 Nexus 프로젝트를 시작했다. 약 4만 권의 데이터를 변환하며 쌓은 노하우와 AX 경험을 개인용 ReadyMD 앱에 담았다는 설명이다.

약 4만 권은 Nexus 프로젝트의 변환 경험으로 표시했다. 이번 작업에서 처리 로그를 독립 집계한 수치나 ReadyMD 출시판의 처리량·성능·품질 보증으로 표시하지 않는다. 사용자가 제공하지 않은 처리 기간, 고객 수, 정확도, 절감률은 추가하지 않았다.

## 페이지 구성

- 기존 공감 섹션 다음에 제작 이야기 `#origin-story`: 연구 전 자료 준비 문제 → AI가 읽기 쉬운 형태의 필요 → Nexus 약 4만 권 → 개인용 ReadyMD.
- 동일 자료 체험 다음에 개인 서재 `#library`: 수백 개의 파일을 매번 고르는 부담 → ReadyMD 변환 → Obsidian 보관함 → 별도 AI 도구로 질문.
- ‘내가 모은 자료에서 이 주제를 설명하는 근거를 찾아줘’는 사용 장면을 위한 질문 예시다. 답변을 생성하거나 실제 검색 결과를 꾸미지 않는다.
- 상단에 ‘나만의 서재’, 푸터에 제작 이야기·서재 링크를 추가했다. FAQ에는 별도 AI 연동과 자료 접근·비용 조건을 설명했다.
- 히어로 제목, 앱 이름, 푸터 별빛, 기존 비교 계산은 보존했다. 정적 서버 컴포넌트만 추가했으며 새 API·모델·인증·DB 연동은 없다.

## 한국어 편집

초안 방향: ‘연구를 시작하려다 토큰을 소모했고, Nexus의 변환 경험을 개인용 앱으로 옮겼다.’

남은 편집 문제: ‘AX’, ‘보관함’, ‘AI 연동’을 설명 없이 쓰면 기능 목록처럼 읽힐 수 있다. 모든 자료를 한 번에 읽거나 자동으로 연결하는 기능처럼 표현하지 않아야 한다.

최종 문구는 ‘연구를 시작하려다 토큰부터 써버렸습니다’, ‘Nexus에서 시작해, ReadyMD로 이어졌습니다’, ‘파일은 수백 개인데, 언제 매번 업로드하나요?’로 정리했다. AX는 AI를 실제 작업에 연결하는 과정으로 문장 안에서 풀었다. 문장을 짧게 나누고 제작자의 경험을 유지했다.

## Obsidian 근거와 기능 범위

공식 자료 확인 2026-09-26.

- [보관 방식](https://obsidian.md/help/data-storage): Obsidian 보관함은 로컬 폴더이며 본문은 Markdown 파일이다.
- [Markdown 가져오기](https://obsidian.md/help/import/markdown): 파일과 폴더를 보관함으로 옮길 수 있다. 본문과 이미지의 상대 경로를 유지하고 결과를 확인하도록 안내했다.
- [AI 연동 예시의 개발자 설명](https://community.obsidian.md/plugins/vault-llm-assistant): 보관함을 대상으로 질문하고 출처를 연결하는 외부 플러그인의 사례를 확인했다. 특정 플러그인을 설치하거나 추천 상품으로 선정한 것은 아니다.

ReadyMD의 자동 Obsidian·AI 연동은 구현했다고 주장하지 않는다. AI 질문·검색에는 별도 플러그인/도구 및 접근 설정이 필요하며 색인·질문 비용과 외부 전송은 선택한 도구에 따라 달라진다. 모든 파일의 동시 완독, 전체 연동 무료, 자동 검색, 정답 보장은 하지 않는다. 실제 Obsidian 가져오기와 AI 검색은 이번 작업에서 실행하지 않았다.
